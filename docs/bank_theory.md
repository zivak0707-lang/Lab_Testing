## №1. Цілочисельні типи

*Кошик · Типи даних*

**Завдання:** Залиште на слайді лише цілочисельні типи даних C#. Усі зайві картки перетягніть у кошик.

### Теорія

#### Суть
Цілочисельний тип зберігає **ціле** число — без дробової частини: `5`, `0`, `-120`. Таких типів кілька, вони відрізняються розміром: що більше пам'яті займає тип, то більші числа в нього вміщуються.
#### Приклад
```
int age = 17;           // 17
long big = 9000000000;  // > int
byte level = 200;       // 0…255
```
Найчастіше використовують `int`. Якщо число не вміщується в `int` — беруть `long`.
#### Типова помилка
Записати дробове число в цілу змінну:
```
int price = 9.99;  // помилка!
```
Для чисел із крапкою потрібен дробовий тип. Ціла змінна також не зберігає текст чи `true`/`false`.
#### Як запам'ятати
Розмір цілих типів подвоюється: `byte` (8 біт) → `short` (16) → `int` (32) → `long` (64). Цілими рахують штуки, роки, бали — те, що не буває «з половиною».

### Підказка (після перевірки з помилками)

Ціле число не має дробової частини. Для кожної картки спитайте: чи можна в такий тип записати `2.5`, текст або `true`? Якщо так — це не цілочисельний тип.

### Правильна відповідь (якщо все правильно або учень сам відкрив після 2 спроб)

#### Правильна відповідь
- Залишаються цілочисельні: `int`, `long`, `short`, `byte`.
- У кошик: `double` і `decimal` — дробові числа, `string` — текст, `bool` — логічне значення (`true`/`false`).

## №2. Значення типу double

*Кошик · Значення та їх типи*

**Завдання:** Залиште на слайді лише значення, які мають тип double. Решту перетягніть у кошик.

### Теорія

#### Суть
Тип числа в коді видно з того, **як його записано**:
- є десяткова крапка і немає букви в кінці — це `double`;
- буква `f` у кінці — `float`, буква `m` — `decimal`;
- ціле число без крапки й букви — зазвичай `int`, а дуже велике (як `5000000000`) — `long`; буква `L` у кінці теж дає `long`;
- лапки `"…"` — це текст `string`, навіть якщо всередині цифри.

Рідше трапляються ще два записи `double`: буква `d` у кінці (`2d`) і запис зі степенем десяти (`1e3` — це 1000.0).
#### Приклад
```
var g = 9.81;    // double
var h = 1.5f;    // float
var p = 99.9m;   // decimal
var n = 10;      // int
var s = "9.81";  // string
var k = 1e3;     // double: 1000
```
Слово `var` означає «тип візьми зі значення праворуч» — тому в коментарях видно, який тип отримала кожна змінна.
#### Типова помилка
Вважати `2.0` цілим числом, бо дробова частина нульова. Крапка є — отже, це `double`. А `7` без крапки — `int`, навіть якщо його записують у змінну `double`.
#### Як запам'ятати
Крапка без букви — `double`. Буква після числа «перемикає» тип: `f` — float, `m` — money (гроші, `decimal`).

### Підказка (після перевірки з помилками)

Дивіться на сам запис значення: чи є крапка, чи є буква в кінці, чи є лапки. Тип `double` — це крапка без жодної букви й без лапок.

### Правильна відповідь (якщо все правильно або учень сам відкрив після 2 спроб)

#### Правильна відповідь
- Тип `double` мають `3.14`, `0.5`, `2.0` і `-7.25`: є крапка і немає букви в кінці.
- `3.14f` — це `float`, `2.5m` — `decimal`, `"3.14"` — `string` (у лапках).
- `5` — це `int`. Його можна записати у змінну `double` (`double x = 5;`), але лише тому, що `int` автоматично перетворюється на `double`. Сам літерал `5` лишається значенням типу `int`.

## №3. Логічні оператори

*Кошик · Оператори*

**Завдання:** Залиште на слайді лише логічні оператори C#. Інші оператори перетягніть у кошик.

### Теорія

#### Суть
Логічні оператори працюють зі значеннями `true` (істина) і `false` (хиба) і дають теж `true` або `false`. Ними з'єднують кілька умов в одну.
- `&&` — «І»: істина, коли обидві частини істинні;
- `||` — «АБО»: істина, коли хоча б одна частина істинна;
- `!` — «НЕ»: змінює `true` на `false` і навпаки;
- `^` — «виключне АБО»: істина, коли істинна рівно одна частина;
- `&` і `|` — теж «І» та «АБО», але завжди обчислюють обидві частини.
#### Приклад
```
bool sunny = true, warm = false;
bool walk = sunny && warm;  // false
bool any  = sunny || warm;  // true
bool rain = !sunny;         // false
bool one  = sunny ^ warm;   // true
```
#### Скорочене обчислення
`&&` і `||` не обчислюють праву частину, якщо відповідь уже відома з лівої: `false && …` — завжди `false`, `true || …` — завжди `true`. Тому так писати безпечно:
```
if (n != 0 && 10 / n > 1) { … }
```
Якщо `n` дорівнює 0, ділення просто не виконається. З `&` воно виконалося б і програма впала б.
#### Типова помилка
Вважати логічними оператори порівняння (`>`, `!=`). Вони теж дають `true`/`false`, але **порівнюють два значення**, а не з'єднують умови.
#### Як запам'ятати
Подвоєний знак (`&&`, `||`) — «економний»: не дивиться на праву частину, якщо вже все ясно.

### Підказка (після перевірки з помилками)

Логічний оператор з'єднує **умови** (`true`/`false`). Якщо оператор порівнює два значення, обчислює число чи змінює змінну — він не логічний.

### Правильна відповідь (якщо все правильно або учень сам відкрив після 2 спроб)

#### Правильна відповідь
- Логічні оператори: `&&` (І), `||` (АБО), `!` (НЕ).
- Зайві: `==` і `<` — порівняння; `+` і `%` — арифметичні; `=` — присвоєння; `++` — збільшення на 1.

## №4. Оператори циклу

*Кошик · break і continue*

**Завдання:** Залиште на слайді лише ключові слова, з яких починається оператор циклу. Решту перетягніть у кошик.

### Теорія

#### Суть
Цикл повторює ті самі дії кілька разів. У C# є чотири види циклів:
- `for` — коли наперед відомо, скільки разів повторювати;
- `while` — «поки умова істинна»: умова перевіряється **перед** кожним повтором;
- `do … while` — умова перевіряється **після** повтору, тому тіло виконується хоча б раз;
- `foreach` — по черзі бере кожен елемент масиву чи списку.
#### Приклад
```
for (int i = 1; i <= 3; i++)
    Console.Write(i);   // 123

int[] a = { 5, 7 };
foreach (int x in a)
    Console.Write(x);   // 57
```
#### Типова помилка
Вважати циклом усе, що трапляється всередині циклу. Оператори, які лише керують уже запущеним циклом (переривають його або пропускають крок), самі циклом не є. Не є циклом і умовний оператор, що вибирає одну з гілок: він нічого не повторює.
#### Як запам'ятати
У циклу завжди є тіло, яке **повторюється**. Якщо оператор нічого не повторює — це не цикл.

### Підказка (після перевірки з помилками)

Цикл **повторює** своє тіло. Подумайте: чи повторює щось цей оператор, чи лише керує циклом зсередини або вибирає одну з гілок?

### Правильна відповідь (якщо все правильно або учень сам відкрив після 2 спроб)

#### Правильна відповідь
- Цикли: `for`, `while`, `do` (цикл `do … while`), `foreach`.
- Зайві: `break` і `continue` керують циклом зсередини, `if` і `switch` — розгалуження, `return` — вихід із методу.

## №5. Значення → тип

*Таблиця відповідностей · Значення та їх типи*

**Завдання:** Перетягніть назву типу в клітинку навпроти значення, яке має цей тип. Дві картки зайві.

### Теорія

#### Суть
Кожне значення, записане прямо в коді (літерал), має тип. Його видно з запису:
- ціле число без крапки — `int`;
- число з крапкою — `double`; з буквою `f` — `float`, з буквою `m` — `decimal`;
- один символ в **одинарних** лапках — `char`;
- текст у **подвійних** лапках — `string`;
- слова `true` і `false` — `bool`.
#### Приклад
```
var a = 7;        // int
var b = 0.5;      // double
var c = 'z';      // char
var d = "zoo";    // string
var e = false;    // bool
var f = 19.99m;   // decimal
```
#### Типова помилка
Плутати `'z'` і `"z"`. Одинарні лапки — рівно один символ (`char`), подвійні — рядок `string`, навіть якщо в ньому одна літера.
#### Як запам'ятати
Одна лапка — один символ. Подвійні лапки — цілий рядок.

### Підказка (після перевірки з помилками)

Зверніть увагу на лапки (одинарні чи подвійні), на крапку в числі і на букву в кінці числа.

### Правильна відповідь (якщо все правильно або учень сам відкрив після 2 спроб)

#### Правильна відповідь
- `42` → `int`
- `3.14` → `double`
- `'A'` → `char` (одинарні лапки)
- `"A"` → `string` (подвійні лапки)
- `true` → `bool`
- `2.5m` → `decimal`
- Зайві: `float` (його літерал має букву `f`, як `3.14f`) і `long` (для дуже великих цілих).

## №6. Опис → оператор

*Таблиця відповідностей · Оператори*

**Завдання:** Перетягніть оператор у клітинку навпроти його опису. Дві картки зайві.

### Теорія

#### Суть
Оператор — це знак дії над значеннями. Деякі оператори схожі на вигляд, але роблять зовсім різне, тому їх треба впізнавати **за дією**.
#### Приклад
```
int x = 10;         // запис: x стає 10
bool eq = x == 10;  // true
bool ne = x != 3;   // true
int r = 17 % 5;     // 2 (остача)
x++;                // x стало 11
x--;                // x знову 10
```
#### Типова помилка
Написати в умові `if (x = 5)` замість `if (x == 5)`. Один знак `=` записує значення, а не порівнює (у C# така умова навіть не скомпілюється).
#### Як запам'ятати
- `==` — «два знаки — порівнюємо дві речі».
- `%` — «що лишилося після ділення порівну».
- `!` перед `=` означає «не».

### Підказка (після перевірки з помилками)

Уявіть дію з опису: записати значення, порівняти два значення, порахувати остачу чи змінити змінну на 1. Схожі на вигляд оператори роблять різне.

### Правильна відповідь (якщо все правильно або учень сам відкрив після 2 спроб)

#### Правильна відповідь
- Остача від ділення → `%`
- Перевірка на рівність → `==`
- Присвоєння значення змінній → `=`
- Збільшення змінної на 1 → `++`
- Не дорівнює → `!=`
- Логічне «І» → `&&`
- Зайві: `||` (логічне «АБО») і `--` (зменшення на 1).

## №7. Опис → тип

*Таблиця відповідностей · Типи даних*

**Завдання:** Перетягніть тип у клітинку навпроти опису значень, які він зберігає. Дві картки зайві.

### Теорія

#### Суть
Тип вирішує, **що** можна зберегти у змінній і **скільки пам'яті** вона займе (1 байт = 8 біт).
- Для цілих чисел є кілька типів різного розміру: що більше байтів, то більше число вміщується.
- Для дробових чисел є `float` (4 байти) і точніший `double` (8 байтів).
- Для символів і тексту — `char` і `string`, для так/ні — `bool`.
#### Приклад
```
byte b = 255;        // максимум byte
int i = 2000000000;  // ~ ±2,1 млрд
long l = 9000000000; // більше за int
double d = 0.1;      // дробове
char c = 'Ж';        // один символ
bool ok = true;      // true/false
```
#### Типова помилка
Думати, що в `byte` можна записати будь-яке ціле:
```
byte b = 300;  // помилка: максимум 255
```
#### Як запам'ятати
Розмір цілих типів подвоюється: 1 → 2 → 4 → 8 байтів (`byte` → `short` → `int` → `long`). `double` — «подвійна» точність порівняно з `float`.

### Підказка (після перевірки з помилками)

Порахуйте розмір: 1 байт = 8 біт. Цілі типи відрізняються розміром, а дробові, символьні й логічні зберігають зовсім інші дані.

### Правильна відповідь (якщо все правильно або учень сам відкрив після 2 спроб)

#### Правильна відповідь
- Ціле від 0 до 255 → `byte`
- Ціле, 32 біти → `int`
- Ціле, 64 біти → `long`
- Дробове подвійної точності → `double`
- Один символ Unicode → `char`
- `true` або `false` → `bool`
- Зайві: `string` (текст) і `short` (ціле, 16 біт).

## №8. Вираз → результат

*Таблиця відповідностей · Значення та їх типи*

**Завдання:** Перетягніть результат у клітинку навпроти виразу C#. Дві картки зайві.

### Теорія

#### Суть
- Якщо **обидва** числа цілі, `/` ділить націло: дробова частина просто відкидається.
- Якщо хоча б одне число дробове, результат теж дробовий.
- `%` дає остачу від ділення.
- Множення і ділення виконуються раніше за додавання і віднімання; дужки змінюють порядок.
- Порівняння і логічні оператори дають `true` або `false`.
#### Приклад
```
9 / 4            // 2  (ціле ділення)
9 % 4            // 1  (остача)
9.0 / 4          // 2.25
1 + 2 * 3        // 7
(1 + 2) * 3      // 9
5 > 1 || 2 > 3   // true
```
#### Типова помилка
Очікувати, що `9 / 4` дасть `2.25`. Поки обидва числа цілі, результат цілий: `2`. Щоб отримати дробову відповідь, запишіть хоча б одне число з крапкою: `9.0 / 4`.
#### Як запам'ятати
«Ціле на ціле — ціле». Порядок дій як у математиці: спочатку `*` `/` `%`, потім `+` `-`.

### Підказка (після перевірки з помилками)

Ціле на ціле — ціле. Спочатку множення, потім додавання. А `&&` дає `true`, лише коли обидві умови істинні.

### Правильна відповідь (якщо все правильно або учень сам відкрив після 2 спроб)

#### Правильна відповідь
- `7 / 2` → `3` (обидва цілі — ділення націло)
- `7 % 2` → `1` (остача)
- `7.0 / 2` → `3.5` (є дробове число)
- `2 + 3 * 4` → `14` (спочатку множення)
- `(2 + 3) * 4` → `20` (спочатку дужки)
- `10 > 5 && 3 > 4` → `false` (друга умова хибна)
- Зайві: `true` і `0`.

## №9. Типи за категоріями

*Номерки на категорії · Типи даних*

**Завдання:** Перетягніть кружечки з номерами на рядки відповідних категорій.

### Теорія

#### Суть
Типи даних зручно ділити на «сім'ї» за тим, **що** вони зберігають:
- **цілі числа** — кількість, номер, рік;
- **дробові (дійсні) числа** — ціна, вага, температура;
- **символи й текст** — одна літера або цілий рядок;
- **логічні значення** — так чи ні (`true`/`false`).
#### Приклад
```
int pupils = 28;       // ціле
double temp = 36.6;    // дробове
char mark = 'A';       // символ
string city = "Київ";  // текст
bool done = false;     // так/ні
```
#### Типова помилка
Плутати `char` і `string`. `char` — рівно один символ в одинарних лапках, `string` — текст у подвійних лапках (він може бути навіть порожнім: `""`).
#### Як запам'ятати
Спитайте себе: «це рахують штуками?» — ціле. «Може бути з комою?» — дробове. «Це буква чи текст?» — символьний або рядковий. «Так чи ні?» — логічний.

### Підказка (після перевірки з помилками)

Для кожного типу спитайте: що він зберігає — кількість, число з комою, літеру чи текст, так чи ні?

### Правильна відповідь (якщо все правильно або учень сам відкрив після 2 спроб)

#### Правильна відповідь
- Цілочисельні: `int`, `long`, `byte`.
- Дійсні (дробові): `float`, `double`, `decimal`.
- Символьні та рядкові: `char`, `string`.
- Логічний: `bool`.

## №10. Оператори за категоріями

*Номерки на категорії · Оператори*

**Завдання:** Перетягніть кружечки з номерами операторів на рядки відповідних категорій.

### Теорія

#### Суть
Оператори поділяють на групи за тим, що вони роблять:
- **арифметичні** обчислюють число: додають, множать, рахують остачу;
- **порівняння** порівнюють два значення і дають `true` або `false`;
- **логічні** з'єднують умови: «І», «АБО», «НЕ»;
- **присвоєння** записують значення у змінну. Складене присвоєння `x -= 3` — те саме, що `x = x - 3`.
#### Приклад
```
int s = 7 * 2 - 1;           // 13
bool big = s > 10;           // true
bool both = big && s != 13;  // false
s -= 3;                      // s = 10
```
#### Типова помилка
Вважати складене присвоєння (`-=`, `*=`) арифметикою. Воно не лише обчислює, а й **записує** результат у змінну — тому належить до присвоєння.
#### Як запам'ятати
Дивіться на результат дії: вийшло число — арифметика; `true`/`false` з двох значень — порівняння; `true`/`false` з умов — логіка; змінилася змінна — присвоєння.

### Підказка (після перевірки з помилками)

Подивіться на результат дії: число, `true`/`false` з порівняння двох значень, `true`/`false` з умов чи змінена змінна?

### Правильна відповідь (якщо все правильно або учень сам відкрив після 2 спроб)

#### Правильна відповідь
- Арифметичні: `+`, `%`.
- Порівняння: `<`, `==`, `>=`.
- Логічні: `&&`, `||`, `!`.
- Присвоєння: `=`, `+=`.

## №11. break чи continue

*Номерки на категорії · break і continue*

**Завдання:** Прочитайте твердження і перетягніть кружечки з їхніми номерами на рядок того оператора, про який іде мова.

### Теорія

#### Суть
Обидва оператори працюють усередині циклу, але роблять різне:
- `break` — «стоп»: цикл закінчується повністю, і програма переходить до коду **після** циклу. Так само `break` завершує гілку `case` в операторі `switch`;
- `continue` — «пропустити»: решта тіла на цьому кроці не виконується, і цикл іде на **наступний** крок.
#### Приклад
```
for (int i = 1; i <= 5; i++)
{
    if (i == 3) continue;
    Console.Write(i);   // 1245
}

for (int i = 1; i <= 5; i++)
{
    if (i == 3) break;
    Console.Write(i);   // 12
}
```
У першому циклі пропущено лише число 3, у другому цикл зупинився на 3.
#### Типова помилка
Думати, що `continue` зупиняє цикл. Він пропускає лише **один** крок, а цикл триває. Зупиняє цикл тільки `break`.
#### Як запам'ятати
`break` — «перерва» (кінець циклу). `continue` — «продовжуй» (з наступного кроку).

### Підказка (після перевірки з помилками)

`break` зупиняє цикл повністю, `continue` лише пропускає поточний крок. Перечитайте твердження: про яку з цих дій у ньому йдеться?

### Правильна відповідь (якщо все правильно або учень сам відкрив після 2 спроб)

#### Правильна відповідь
**break**:
- повністю завершує виконання циклу;
- виходить із гілки `case` у `switch`;
- після нього виконується перший оператор, що стоїть після циклу.

**continue**:
- пропускає решту тіла лише на поточній ітерації;
- після нього цикл продовжується з наступної ітерації;
- у `for` після нього виконується `i++`, а потім перевірка умови.

## №12. Літерали за категоріями

*Номерки на категорії · Значення та їх типи*

**Завдання:** Перетягніть кружечки з номерами значень на рядки відповідних категорій літералів.

### Теорія

#### Суть
Літерал — це значення, записане прямо в коді. За записом видно його «сім'ю»:
- **цілочисельні** — без крапки; можуть мати букву `L` у кінці (тип `long`) або починатися з `0x` — це запис у шістнадцятковій системі;
- **дійсні** — з крапкою або з буквою `f`, `d` чи `m` у кінці (навіть без крапки: `2f`, `5d`);
- **символьні** — в одинарних лапках, **рядкові** — у подвійних;
- **логічні** — лише два слова: `true` і `false`.
#### Приклад
```
long big = 5000000000L; // цілий
int mask = 0x1F;        // 31, цілий
float k = 2f;           // дійсний
decimal sum = 10m;      // дійсний
char c = 'Ж';           // символ
```
#### Типова помилка
Вважати `0x1F` текстом через букви `x` і `F`. Це звичайне ціле число, записане в шістнадцятковій системі: `0x10` дорівнює 16.
#### Як запам'ятати
Буква в кінці числа змінює тип, але не «сім'ю»: з `L` число лишається цілим, а `f`, `d` і `m` роблять його дробовим.

### Підказка (після перевірки з помилками)

Дивіться на запис: крапка, буква в кінці (`L`, `f`, `d`, `m`), лапки або початок `0x`.

### Правильна відповідь (якщо все правильно або учень сам відкрив після 2 спроб)

#### Правильна відповідь
- Цілочисельні: `100`, `100L`, `0xFF` (дорівнює 255).
- Дійсні: `1.5`, `1.5f`, `2.5m`.
- Символьні та рядкові: `'x'`, `"x"`.
- Логічні: `true`, `false`.

## №13. for, break і continue

*Слова в пропуски · break і continue*

**Завдання:** Перетягніть слова в пропуски. Одне слово можна використати кілька разів.

### Теорія

#### Суть
Цикл `for` має лічильник, тому його обирають, коли кількість повторів відома заздалегідь. Усередині будь-якого циклу можна керувати його ходом: зупинити цикл повністю або пропустити один крок.
#### Приклад: пропустити і зупинити
```
for (int i = 1; i <= 10; i++)
{
    if (i % 2 == 0) continue;
    if (i > 7) break;
    Console.Write(i);  // 1357
}
```
`continue` пропустив парні числа (цикл пішов далі), а `break` зупинив цикл, коли `i` стало 9.
#### Приклад: switch
```
switch (day)
{
    case 6:
    case 7: s = "Вихідний"; break;
    default: s = "Будній"; break;
}
```
Для 6 і 7 виконується той самий код — гілки можна писати поспіль. Кожну гілку `case` завершують оператором, який виходить зі `switch`.
#### Типова помилка
Думати, що `continue` завершує цикл. Він лише пропускає поточний крок, а цикл триває.
#### Як запам'ятати
`break` — «гальмо» (стоп), `continue` — «далі» (наступний крок).

### Підказка (після перевірки з помилками)

Яке слово зупиняє цикл, а яке лише пропускає крок? І який цикл має лічильник?

### Правильна відповідь (якщо все правильно або учень сам відкрив після 2 спроб)

#### Правильна відповідь
- Цикл `for` — з лічильником, для відомої кількості повторів.
- `break` повністю завершує цикл: далі виконується оператор після циклу.
- `continue` цикл не завершує, а лише пропускає решту тіла на поточній ітерації.
- Гілку `case` у `switch` теж завершує `break` — тому `break` потрібен двічі.
- Зайві: `while`, `return`, `goto`.

## №14. Вибір типу даних

*Слова в пропуски · Типи даних*

**Завдання:** Перетягніть назви типів у пропуски. Одне слово можна використати кілька разів.

### Теорія

#### Суть
Тип змінної обирають за тим, **що** в ній зберігатиметься:
- ціле число — найчастіше `int`, а якщо воно може бути дуже великим — `long`;
- дробове число — `double`; для грошей беруть `decimal`, бо він рахує без похибок округлення;
- текст — `string`, одна літера — `char`;
- так/ні — `bool`.
#### Приклад
```
int floor = 9;            // поверх
long people = 8100000000; // населення
double height = 1.75;     // зріст
decimal price = 49.90m;   // ціна
string name = "Оля";      // ім'я
char initial = 'О';       // літера
```
#### Типова помилка
Зберігати гроші в `double`:
```
double s = 0.1 + 0.2;
// 0,30000000000000004
```
`double` зберігає дроби наближено. `decimal` рахує точно, тому його використовують для цін і сум.
#### Як запам'ятати
Буква `m` у `49.90m` — від слова money: гроші → `decimal`.

### Підказка (після перевірки з помилками)

Спитайте себе, що саме зберігається: кількість, дуже велике число, число з комою, гроші, текст чи одна літера.

### Правильна відповідь (якщо все правильно або учень сам відкрив після 2 спроб)

#### Правильна відповідь
- Цілі числа — `int`; лічильник циклу `for` — теж `int` (тому `int` потрібен двічі).
- Дуже великі цілі — `long`.
- Число `3.14` без суфікса — `double`.
- Гроші — `decimal`.
- Текст — `string`, один символ — `char`.
- Зайві: `bool` (лише `true`/`false`) і `void` (означає «немає значення»: так позначають методи, а не змінні).

## №15. Оператори в реченнях

*Слова в пропуски · Оператори*

**Завдання:** Перетягніть оператори в пропуски. Один оператор можна використати кілька разів.

### Теорія

#### Суть
- Оператори порівняння (`==`, `!=`, `>`) відповідають на питання «так чи ні?».
- Арифметичні (`/`, `%`) обчислюють число.
- Логічні (`&&`, `||`) з'єднують кілька умов в одну.
- А `=` нічого не перевіряє — він **записує** значення у змінну.
#### Приклад
```
int k = 8;                     // запис
bool same = k == 8;            // true
bool diff = k != 8;            // false
int rest = 14 % 4;             // 2
bool inside = k > 1 && k < 5;  // false
```
В останньому рядку перша умова істинна, друга — хибна, тому «І» дає `false`.
#### Типова помилка
Написати `if (k = 8)`: один знак `=` — це запис, а не перевірка. Для порівняння потрібно `k == 8`.
#### Як запам'ятати
Читайте оператори вголос:
- `=` — «стає»; `==` — «дорівнює?»; `!=` — «не дорівнює?»;
- `%` — «остача від ділення на»;
- `&&` — «і водночас»; `||` — «або».

### Підказка (після перевірки з помилками)

Читайте оператори вголос: `=` — «стає», `==` — «дорівнює?», `%` — «остача від ділення на». Для двох умов, які мають бути істинними водночас, потрібне «І».

### Правильна відповідь (якщо все правильно або учень сам відкрив після 2 спроб)

#### Правильна відповідь
- `5 == 5` повертає `true` — це порівняння.
- `=` записує значення у змінну.
- `%` — остача від ділення: `10 % 3` дорівнює `1` (тому `%` потрібен двічі).
- `a != b` — істина, коли значення різні.
- `x > 0 && x < 10` — обидві частини мають бути істинними.
- Зайві: `||` (досить однієї істинної частини) і `/` (ділення, а не остача).

## №16. while, do…while і foreach

*Слова в пропуски · break і continue*

**Завдання:** Перетягніть слова в пропуски. Одне слово можна використати кілька разів.

### Теорія

#### Суть
- `while (умова) { … }` — спочатку перевіряє умову, потім виконує тіло. Якщо умова хибна від самого початку, тіло не виконається жодного разу.
- `do { … } while (умова);` — спочатку виконує тіло, потім перевіряє умову. Тіло виконається щонайменше один раз.
- `foreach` по черзі бере кожен елемент масиву чи списку.
#### Приклад
```
int n = 0;
while (n > 0) n--;   // 0 разів

do { n++; } while (n < 0);
Console.Write(n);    // 1

string[] days = { "Пн", "Вт" };
foreach (string d in days)
    Console.Write(d); // ПнВт
```
Умова `n < 0` хибна, але тіло `do` все одно виконалося один раз.
#### Типова помилка
Забути крапку з комою в кінці циклу `do … while`. Саме тут вона обов'язкова: `} while (n < 0);`
#### Як запам'ятати
`do` — «спочатку зроби, потім перевір». `foreach` — «для кожного» елемента.

### Підказка (після перевірки з помилками)

Котрий цикл перевіряє умову **до** першого виконання тіла, а котрий — **після**? А котрий перебирає елементи по черзі?

### Правильна відповідь (якщо все правильно або учень сам відкрив після 2 спроб)

#### Правильна відповідь
- `while` перевіряє умову **перед** ітерацією — тіло може не виконатися жодного разу.
- `do … while` перевіряє умову **після** ітерації — тіло виконається хоча б раз (тому `do` потрібне двічі).
- `foreach` — перебір усіх елементів масиву.
- `break` — достроковий вихід із будь-якого циклу.
- Зайві: `continue` (лише пропускає крок) і `if` (не цикл).

## №17. Обмін значень двох змінних

*Порядок кроків · Алгоритми*

**Завдання:** Розставте рядки програми обміну значень змінних a і b у правильному порядку (крок 1 — перший).

### Теорія

#### Суть
Змінна зберігає лише **одне** значення. Коли записуєш у неї нове, старе зникає назавжди. Тому, щоб поміняти значення двох змінних місцями, потрібна третя, **допоміжна** змінна — «тимчасова кишеня» для одного зі значень.
#### Приклад: зберегти, перш ніж затерти
```
int score = 40;
int old = score;  // запам'ятали 40
score = 100;      // затерли
// old досі дорівнює 40
```
#### Аналогія
Щоб поміняти вміст двох склянок (сік і вода), потрібна третя, порожня склянка. Спочатку в неї переливають одну рідину — тоді звільнена склянка може прийняти іншу.
#### Типова помилка
```
x = y;   // x отримало значення y
y = x;   // y отримало те саме!
```
Тепер обидві змінні однакові: старе значення `x` втрачено.
#### Як запам'ятати
Перш ніж затирати змінну, збережи її значення. Показувати результат — лише коли обмін завершено.

### Підказка (після перевірки з помилками)

Перевірте, чи не губиться старе значення: перш ніж затерти змінну, його треба зберегти.

### Правильна відповідь (якщо все правильно або учень сам відкрив після 2 спроб)

#### Правильний порядок
1. `int a = 5, b = 8;` — оголошуємо змінні.
2. `int temp = a;` — зберігаємо старе значення `a`.
3. `a = b;` — тепер `a` можна затерти.
4. `b = temp;` — у `b` записуємо збережене значення.
5. Виводимо результат: `a = 8, b = 5`.

## №18. Пошук найбільшого елемента

*Порядок кроків · Алгоритми*

**Завдання:** Розставте кроки алгоритму пошуку найбільшого елемента масиву arr у правильному порядку.

### Теорія

#### Суть
Програма шукає найбільше число так, як суддя на змаганнях: тримає в пам'яті «поточного лідера» і по черзі порівнює з ним кожного наступного учасника. Якщо хтось кращий — він стає новим лідером. Коли переглянуто **всіх**, лідер і є відповіддю.
#### Приклад: заміна лідера
```
int best = 3;
int score = 7;
if (score > best)
    best = score;   // best = 7
```
#### Типова помилка
- Почати з `max = 0`. Якщо всі числа від'ємні, відповідь буде хибною: 0, якого в масиві немає. Початкового лідера беруть із самого масиву.
- Виводити результат усередині циклу: на екрані з'явиться кожен проміжний лідер, а не відповідь.
#### Як запам'ятати
Переможця оголошують лише тоді, коли переглянули **всіх** учасників.

### Підказка (після перевірки з помилками)

Подумайте, що потрібно мати перед першим порівнянням і в який момент можна оголошувати переможця.

### Правильна відповідь (якщо все правильно або учень сам відкрив після 2 спроб)

#### Правильний порядок
1. Створити масив `arr` і заповнити числами — без даних нічого шукати.
2. `max = arr[0]` — перший елемент стає «поточним лідером».
3. Цикл по решті елементів (з другого).
4. Якщо `arr[i] > max`, то `max = arr[i]`.
5. Після циклу вивести `max`.

## №19. Виконання циклу for

*Порядок кроків · Алгоритми*

**Завдання:** Цикл: for (int i = 0; i < 3; i++) Console.Write(i); Розставте дії в тому порядку, у якому їх виконує програма на початку роботи циклу.

### Теорія

#### Суть
Заголовок циклу `for` складається з трьох частин, розділених крапкою з комою:
```
for (початок; умова; крок)
```
- **початок** (ініціалізація) створює лічильник;
- **умова**: поки вона істинна, тіло циклу виконується;
- **крок** (ітератор) змінює лічильник.
#### Те саме через while
Цикл `for` можна переписати через `while` — так видно, де стоїть кожна частина:
```
int k = 10;            // початок
while (k > 8)          // умова
{
    Console.Write(k);  // тіло
    k--;               // крок
}
// виведе 109
```
#### Типова помилка
Думати, що крок (`i++`) виконується на самому початку кожного повтору. Насправді він іде **після** тіла циклу.
#### Як запам'ятати
Початок виконується лише **один** раз — до першої перевірки умови.

### Підказка (після перевірки з помилками)

Початок виконується лише один раз. А крок (`i++`) іде до чи після тіла циклу?

### Правильна відповідь (якщо все правильно або учень сам відкрив після 2 спроб)

#### Правильний порядок
1. Ініціалізація `int i = 0` — лише один раз.
2. Перевірка умови `i < 3` (0 < 3 — істина).
3. Тіло: `Console.Write(i)` виводить 0.
4. Ітератор `i++` — тепер `i = 1`.
5. Повторна перевірка умови (1 < 3 — істина).
6. Тіло: виводиться 1.

## №20. Сума непарних чисел з continue

*Порядок кроків · Алгоритми*

**Завдання:** Розставте кроки програми, яка обчислює суму непарних чисел від 1 до n, у правильному порядку.

### Теорія

#### Суть
Суму рахують «накопичувачем»: змінну для суми створюють і обнуляють ще **до** циклу, а в тілі циклу додають до неї числа по одному.

`continue` пропускає решту тіла на поточному кроці: усе, що стоїть **після** нього, цього разу не виконується.
#### Приклад: пропустити число
```
for (int i = 1; i <= 5; i++)
{
    if (i == 3) continue;
    Console.Write(i);  // 1245
}
```
#### Приклад: перевірка на парність
```
bool even = x % 2 == 0;
// true, якщо x ділиться на 2
```
#### Типова помилка
Обнуляти суму **всередині** циклу: тоді вона щоразу починається з нуля, і в результаті лишається тільки останнє число.
#### Як запам'ятати
`continue` — як сито: те, що відсіяли, далі по тілу циклу не пройде.

### Підказка (після перевірки з помилками)

Сума має бути готова ще до циклу, а парні числа треба відсіяти **раніше**, ніж вони потраплять у суму.

### Правильна відповідь (якщо все правильно або учень сам відкрив після 2 спроб)

#### Правильний порядок
1. Зчитати `n` і обнулити суму — до циклу.
2. Почати цикл `for (int i = 1; i <= n; i++)`.
3. `if (i % 2 == 0) continue;` — парні числа пропускаємо.
4. `sum += i;` — сюди доходять лише непарні.
5. Після циклу вивести `sum`.
